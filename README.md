Для первой задачи "Определение тональности текста" была выбрана модель twitter-roberta-base-sentiment-latest,
к которой происходит обращение через pipeline из библиотеки transformers от huggingface. 
Модель принимает ввод текста на вход и выдаёт массив из словарей, в каждом из которых содержится "label" и "score".
Документация: https://huggingface.co/cardiffnlp/twitter-roberta-base-sentiment-latest

Для второй задачи "Классификация изображений" (Вывод самого вероятного объекта на изображении) используется 
библиотека torchvision и модель Resnet50 с готовыми весами. Файл изображения преобразует в объект торч тензора, 
который является многомерной таблицей элементов, содержащий информацию о том каково наличие канала цвета в каждом 
пикселе изображения. Дальше модель выполняет работу и  выходящие данные преобразуются в понятный для пайтона формат.
Документация: https://docs.pytorch.org/vision/main/models?utm_source=chatgpt.com

Для третьей задачи "Автоматические распознование речи из аудио" был использован pipeline от huggingface для обращения к
инференесу модели whisper-base от open-ai. Для чтения аудиофайлов понадобилось устанавливать пакет winget install "FFmpeg (Essentials Build)" иначе выдавало ошибку.
Документация: https://huggingface.co/docs/transformers/tasks/asr
